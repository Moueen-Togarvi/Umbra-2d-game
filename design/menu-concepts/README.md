# Umbra main menu image concepts

Ten 16:9 image-based main-menu directions generated with the built-in ImageGen workflow.

1. **Lantern Veil** — blossom tree, home light, editorial right-side menu
2. **Moon Gate** — monumental moon portal, centered composition
3. **Home Through Fog** — distant cottage, quiet valley, left-side menu
4. **White Blossom** — graphic black field, blossom canopy, horizontal menu
5. **The Long Shadow** — doorway beam and vampire-shaped shadow
6. **Red Omen** — dark forest and restrained vampire-eye red
7. **Flooded Cathedral** — reflective water and ruined gothic arches
8. **Hanging Bridge** — fog chasm, distant castle, adventure emphasis
9. **Forest Procession** — layered side-on forest built for parallax
10. **Castle Threshold** — monumental doorway and distant home light

These are visual direction samples. For the selected direction, the final game implementation should use the generated image as layered/background art and render the real wordmark and menu controls in Flutter for crisp text, accessibility, hover/focus states, responsive layout, and animation.
